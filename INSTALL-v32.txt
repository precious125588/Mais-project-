WHAT v32 FIXES — THE "1.1 GOES SILENT" BUG
  • The TikTok picker card title is rendered in stylized Unicode (𝙏𝙄𝙆𝙏𝙊𝙆 …). The old
    regexes (/reply with the number/i …) were ASCII-only, so they NEVER matched the
    quoted card -> every gate evaluated false -> the reply fell through with no answer.
  • v32 folds the quoted text through NFKD (𝙏->T, fullwidth digits -> 1..9) before
    matching, and the dispatch gate now fires whenever the reply QUOTES any message
    (not only when a picker is already live), so a quoted "1.1" always reaches the
    picker consumer.
  • The picker + quote handler now lives NATIVELY in mias/index.js (no external .cjs).
    The picker card is re-shown as an IMAGE CARD built by the pipeline when a choice
    is bad or the menu expired.

THE DISK MEDIA PIPELINE (mias/lib/mediaPipeline.cjs)
  • Every download streams to disk; every large upload streams FROM disk
    (sock.sendMessage is wrapped) — media never sits in the bot's RAM, so downloads
    and uploads stay fast and never slow the bot down.
  • Premium output engine chain:  image cards  @napi-rs/canvas -> canvas -> sharp(SVG) -> jimp
                                  video        ffmpeg-static normalize (h264/yuv420p/+faststart)
  • Safety: per-file size cap + TTL sweeper so the workspace can never fill the disk.
  • Type  .pipeline  in chat to see live engine + disk status.
