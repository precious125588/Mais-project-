What it does:
 - Any file that cannot be required prints: what broke, which file required it,
   the reason in plain words, the full require chain, and the stack -> exit 1.
 - Any fix pack that fails to install crashes instead of logging and continuing.
 - Log lines like "failed to load", "install failed", "N failed",
   "parent boot FAILED", "not loaded correctly" are treated as fatal.
 - uncaughtException + unhandledRejection print a full report and exit 1.
 - So the bot can no longer pair to WhatsApp while a feature is silently dead.

Optional in your own boot code:
   STRICT.assertBootClean(['mias/index.js', 'pair.js', 'sessionPaths.js']);
   STRICT.step('label', () => somethingThatMightFail());

Escape hatch: MAIS_STRICT=0 -> everything above only warns (old behaviour).
