1. THERE IS NO PLUGIN FOLDER LOADER. mias/plugins/ IS DEAD.
--------------------------------------------------------------------
There is NO PluginSystem, NO auto-discovery, NO readdirSync() over
mias/plugins/ anywhere in this repository. Verified:

    rg -n "readdirSync" | grep -i plugin      ->  no results

The identifier `plugins` inside mias/index.js (line ~16856) is ONLY the
registry Map for the `.install <gist-url>` owner command. It is a list of
remote URLs — it never reads the mias/plugins/ directory.

=> Any file you drop into mias/plugins/ is never required, never executed,

DO NOT create mias/plugins/*.js. DO NOT create another "fix pack".


2. WHERE COMMAND FIXES ACTUALLY GO
--------------------------------------------------------------------
Load order at runtime:

    server.js / index.js
      -> precious-master-fix-boot.cjs bootParent()
      -> mias/index.js            (all cmd(...) registrations run here)
           ...
           bootChild()            (installs v20 -> v21 -> gst-picker ->
                                   v23-rc -> playv2 -> watermark -> v24 ->
                                   v27 -> v28 -> v29 -> tt-quote)
           v30 FINAL BLOCK
           PRECIOUS-FIX MERGED INLINE BLOCK   <= last writer wins

LAST REGISTRATION WINS. cmd() overwrites any earlier handler with the same
name and logs "[registry] overwrite: <name>".

This matters: precious-fixes-v21.cjs registers .play at bootChild time. Any
.play registered earlier in mias/index.js is destroyed. That is why the
merged block sits at the very BOTTOM of mias/index.js — after bootChild().

To change .play / .video / .getpp / .add / .nsfw / .xnxxdl / .xvideosdl:
    EDIT THE BLOCK `(function __preciousFixMerged() {...})()`
    AT THE END OF mias/index.js — IN PLACE.
For anything else: edit the owning module (mias/precious-fixes-vXX.cjs) in
place. Never add a new file.
